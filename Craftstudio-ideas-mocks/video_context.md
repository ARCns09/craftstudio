## Executive Summary
This video demonstrates the **Live Texture Editor** mod for Minecraft (Fabric). The mod provides an in-game pixel art editor—similar to Photoshop embedded within Minecraft—allowing players and creators to modify block textures, items, entities, GUIs, and sky elements live in-game without restarting or using external software.

---

## Key Features & Highlights

### 1. Installation & Requirements [00:00:43]
- Downloadable via **Modrinth**.
- Requires **Fabric** mod loader (supported on Minecraft 1.21 / 1.21.4 / 1.21.10+).
- Requires configuring keybinds for enabling editor mode (`J` by default), block editor (`R` by default), and hiding edits (`X` by default).

### 2. Live In-Game Pixel Art Editor [00:02:03]
- Works with both vanilla textures and active equipped resource packs (e.g., Bare Bones or Unique Dark) [00:01:48].
- Includes full suite of pixel art tools:
  - Pencil, Brush, Eraser, Fill tool, Eyedropper, Line tool.
  - Hex color code input for custom color selection.
  - Zoom controls, Undo, and Redo.
- **Apply Live [00:02:49]:** Instantly renders changes onto the world and blocks in real-time.

### 3. Block Face Editing [00:03:36]
- Supports multi-sided textures (Up, North, South, West, East, Down).
- Requires saving/applying per face when altering multi-face blocks like grass [00:04:06].

### 4. Sky, GUI & Global Texture Selection [00:05:00]
- Looking directly at the sky opens a global texture directory containing every block, item, mob, sky/sun/moon element, and GUI (e.g., hotbar) [00:05:04].
- Allows customizing game menus, HUDs, and astronomical bodies directly.

### 5. Exporting Custom Resource Packs [00:06:27]
- Tracks all modified assets in a single menu overview [00:06:11].
- Export functionality lets users assign a title, description, author name, and custom icon [00:06:35].
- Automatically compiles and exports directly into the Minecraft `resourcepacks` directory for easy sharing with friends [00:06:51].

### 6. Quick Comparison Feature [00:07:25]
- Hold the hide key (`X` by default) to temporarily hide active live edits and compare custom textures against default textures [00:07:41].
